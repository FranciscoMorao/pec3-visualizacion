# Hotel Booking Cancellations Dashboard

Visualización narrativa interactiva sobre patrones de cancelación hotelera utilizando HTML, CSS, JavaScript y Chart.js.

## Objetivo

Analizar qué factores influyen en la cancelación de reservas hoteleras y presentar los resultados mediante técnicas de data storytelling y visualización interactiva.

## Variables analizadas

- Tipo de hotel
- Antelación de la reserva
- Canal de distribución
- Tipo de cliente

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Chart.js
- GitHub Pages

## Resultados principales

- Los hoteles urbanos presentan una mayor tasa de cancelación.
- Las reservas con mayor antelación tienen más riesgo de cancelarse.
- Las reservas intermediadas muestran mayores tasas de cancelación.
- Los clientes transitorios cancelan con más frecuencia.
